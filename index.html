Model notes
  • Premium payment years. The notebook's investment sets 3 years, but the forecast function ignores it and hard-codes the plan's 8-year term. This page defaults to 8 so it matches the notebook, and lets you change it.
  • Welcome bonus. The notebook adds the bonus rate (0.03 = 3%) directly as dollars, so it contributes cents rather than a percentage of premium. Tick the box on the left to use rate × annual premium.
  • Welcome bonus tiers use the policy year as the "premium number", which is only right for annual payments.
  • Not modelled: premium holiday, top-up premiums by choice, surrender, and switching funds.
  • Fund data is a snapshot (see data/funds.json). Dividends are a fixed amount per unit per year.
  • Random numbers come from a seeded JavaScript generator, so the same seed gives a different path than numpy would.
